## 1. Test Overview

Verify that the COM system is able to configure NE for COM operation using the following information received from VISTA.

**[CHG-008 반영]** Overshooting Cell Detection 과 Resolution 알고리즘 검증을 포함한다.

---

## 2. Test Purpose

1) Check the Overshooting Cell Detection and Resolution algorithm.
2) Check if the COM configure NE for COM operation using the following information received from VISTA.

---

## 3. Dependency & Limitation

1) **Required Network Elements**
   - Network Elements Dependency: Analytic Server

2) **Interfaces & Protocols**
   - I/F & Protocol Name: REST APIs provided by Samsung VISTA-RIC framework

3) **Related Radio Technology**
   - Radio Technology: NR

---

## 4. Related Feature

- **[COA-CSON0003]** NR Overshooting Problem Detection and Resolution
- **[FR13]** NR Coverage Optimization Manager should be able to configure NE for COM operation using the following information received from VISTA:
  - NE List
  - Network Freeze information
  - Sector exclusion cell list
  - Dynamic sector list

## 5. Precondition

### A. Precondition

#### 1. Test environments

1) NR cells (with Overshooting Cell)
2) Statistics items must be collected during comResolutionPeriod

**[CHG-009 반영]** 수집해야 할 PM counter 항목:
- Availability
- Timing Advance
- Air MAC Packet
- Total PRB Usage
- Downlink MIMO
- Downlink Wideband CQI
- Downlink Wideband CQI as SCell
- CU-CP CSL per gNB (Hexa)
- SA CU-CP CSL per gNB with DU Identifier
- Intra SN Pscell Change per gNB with DU Identifier
- Inter SN Pscell Change per gNB with DU Identifier
- UE associated Logical NG-Connection Establishment with DU Identifier
- NR Handover Incoming with DU Identifier
- NR Handover Outgoing with DU Identifier
- UE Connection Number per gNB per PLMN with DU Identifier
- RRC Connection Information with DU Identifier

#### 2. Pre-configuration

**[CHG-001 반영]** NE List 정의:
- **Type 1 NE List**: CM/PM 데이터 관리 대상 NE 목록
- **Type 2 NE List**: Overshooting Cell Detection and Resolution 기능이 적용될 NE 목록 (Type 1 NE List 기반 구성)
- Type 1 NE list excludes NEs included in the exclusion list

**[CHG-005 반영]** Frequency 조합 조건:
- File containing information for Overshooting Detection and Resolution provides different combinations for different Carrier frequency
- NE List contains cells of different carrier frequency
- 주파수 조합 예시:
  - f1=2100MHz: Detection=ON, f2=1800MHz: Detection=ON
  - f1=2100MHz: Detection=ON, f2=1800MHz: Detection=OFF
  - f1=2100MHz: Detection=OFF, f2=1800MHz: Detection=ON
  - f1=2100MHz: Detection=OFF, f2=1800MHz: Detection=OFF

## 6. Test Procedure

### B. Test Procedure

#### 1. Configure the following data from VISTA for a target cluster.

**[GUI_Data1]** Optimization period "Optimization_Start" and "Optimization_End" in Type2 NE list

**[GUI_Data2]** Coverage carrier, Target carriers, and Target carriers' consideration
- "Coverage_Carrier", "Target_Carrier#1", "Target_Carrier#1_Preference", "Target_Carrier#2", "Target_Carrier#2_Preference", "Target_Carrier#3", "Target_Carrier#3_Preference" in Type2 NE list

**[GUI_Data3]** (Optional) Type1 NE list

**[CHG-004 반영]** Cluster 별 Optimization period 설정:
- Operator 가 VISTA UI 를 통해 cluster 별 optimization period 를 설정한다.
- COM uses the optimization period for each cluster and the information for each cell (cluster, antenna azimuth (optional) and cell-RET mapping (optional)) entered by the operator with the VISTA UI.

**[CHG-002 반영]** VISTA 로부터 수신하는 정보 항목:
- **NE List**: Type 1 과 Type 2 NE 목록
- **Network Freeze information**: 네트워크 동결 정보
- **Sector exclusion cell list**: 섹터 제외 셀 목록
- **Dynamic sector list**: 동적 섹터 목록

#### 2. Check if the COM update the NE list with the following condition and time

**Condition:**

1) The NE list read by VISTA is assumed to be Type 1 NE list.

2) Configure the Type 2 NE List to which the overshooting cell detection and resolution function will be applied as follows:
   - Based on Type 1 NE List.
   - Type 1 NE list excludes NEs included in the exclusion list.

3) If VISTA's NE list is changed compared to the previous cycle, COM operates as follows:
   - If the NE list is added, it is added to the NE list managed by COM. (In this case, since there is no collected CM and PM information, it is excluded from this cycle COM operation. It is then included in the CM and PM collection targets for the next cycle COM operation.)
   - If the NE list is deleted, delete it from the NE list managed by COM. (In this case, it is excluded from the COM operation of this cycle.)

**[CHG-010 반영]** NE List 변경 시나리오 검증:
- NE List 추가 시: 다음 cycle 에 포함됨 검증
- NE List 삭제 시: 즉시 제외됨 검증

4) COM uses the optimization period for each cluster and the information for each cell (cluster, antenna azimuth (optional) and cell-RET mapping (optional)) entered by the operator with the VISTA UI.

5) COM uses the coverage carrier information entered by the operator with the VISTA UI.
   - The COM should be able to operate even if the operator do not entering the coverage carrier.

6) [VISTA UI] Operator should set overshooting cell detection switch to ON to detect overshooting cell for a specific carrier.

7) [VISTA UI] Operator should set both overshooting cell detection switch and overshooting cell resolution switch to ON to resolve overshooting problem for a specific carrier.

**[CHG-006 반영]** ESM operation time 고려:
- ESM operation time 을 고려하여 PM counter 수집 제외 시간 (exceptionPMcollectionTime) 을 관리하는지 확인
- ESM operation time 은 cluster 내 모든 cell 의 ESM operation time superset 으로 계산됨
- exceptionPMcollectionTime 값은 2 주간 관리됨 (fallback operation 용)

**[CHG-007 반영]** Cell-RET mapping 검증:
- RET information mapping 이 올바르게 되었는지 확인 (o-ran-ru-id, antenna-line-device-id, antenna-id)
- Cell-RET mapping 이 불가능한 cell 은 Stable Cell Set 에서 제외됨

**Time:**

1) When COM is first run

2) Before D-1 COM algorithm operation (every Friday or Saturday)
   - Since at least one day's worth of CM and PM information should be collected in order to be judged as a valid cell set, the NE list should be updated before collecting D-1 data (Saturday data).

3) Before COM algorithm operation (every Sunday)

## 7. Pass/Fail Criteria

### C. Pass/Fail Criteria

**[CHG-003 반영]** 구체적 Pass/Fail 기준:

1. The COM parameter should be configured normally from VISTA.
   - **Pass**: Type 2 NE List 가 Type 1 NE List 기반으로 올바르게 구성되었음
   - **Pass**: Exclusion list 에 포함된 NE 가 Type 2 에서 제외되었음
   - **Fail**: Type 2 NE List 구성이 Type 1 NE List 와 불일치

2. COM should be able to read the information required for NE and COM operation from VISTA to configure NE list and use it for COM operation.
   - **Pass**: NE List, Network Freeze information, Sector exclusion cell list, Dynamic sector list 모두 정상 수신됨
   - **Pass**: VISTA UI 를 통해 설정한 coverage carrier, optimization period, switch 설정이 COM 에 반영됨
   - **Fail**: 필수 정보 (NE List 등) 수신 실패
   - **Fail**: Switch 설정 (Detection/Resolution ON/OFF) 이 COM 에 반영되지 않음

3. **[CHG-006 반영]** ESM operation time 관리 검증:
   - **Pass**: exceptionPMcollectionTime 이 cluster 별 superset 으로 올바르게 계산됨
   - **Pass**: 2 주간 exceptionPMcollectionTime 이 관리됨

4. **[CHG-007 반영]** Cell-RET mapping 검증:
   - **Pass**: RET information mapping 이 올바르게 수행됨
   - **Pass**: mapping 불가 cell 이 Stable Cell Set 에서 제외됨
